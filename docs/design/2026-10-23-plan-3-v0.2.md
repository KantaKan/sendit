# sendit v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a sendit you can install and leave running. v0.2.0 adds a Settings page, a tray icon with close-to-tray, start on sign-in, single instance, and history that persists across restarts.

**Architecture:** The core gets a runtime `Settings` (alias, download folder, PIN) behind a `Mutex`, so changes take effect without a restart. It also gets a shared `write_atomic` helper. The Tauri shell owns two files in the app data dir, `settings.json` and `history.json`, plus the tray, the window lifecycle and the autostart and single-instance plugins. The frontend stores history as opaque ticket JSON (through `save_history`/`load_history`) and adds a full-page `Settings.svelte`.

**Tech Stack:** Rust (tokio, axum, serde_json), Tauri 2 (`tray-icon` feature, `tauri-plugin-autostart`, `tauri-plugin-single-instance`), Svelte 5 runes, Vitest + @testing-library/svelte, Playwright (mock bridge).

**Spec:** `docs/design/2026-10-23-v0.2-design.md`

## Global Constraints

- Commits use only the user's git identity. **No `Co-Authored-By` or other tool-attribution trailers**, in commits or PRs.
- English UI copy. No emoji, no stock icon sets. Use the existing tokens in `app/src/app.css` (`--surface`, `--line`, `--muted`, `--faint`, `--accent`, `--accent-ink`, `--danger-*`) and the easing `cubic-bezier(0.22, 1, 0.36, 1)`, never overshoot.
- History cap: **500** finished items, newest last on disk.
- Alias: trimmed, max **64** characters, empty is rejected.
- Defaults when `settings.json` is missing or corrupt: hostname, `Downloads/sendit`, no PIN, close to tray.
- Start on sign-in is **off by default**. The value shown is always read back from the plugin.
- Clearing history never deletes files.
- Writes of `settings.json`, `history.json` and `trust.json` are atomic (temp file, then rename).
- Version after this plan: **0.2.0** (workspace `Cargo.toml`, `app/package.json`, `app/src-tauri/tauri.conf.json`).

## Review Focus

1. **A history save that races the initial load.** If any save runs before `load_history` resolves, `history.json` is overwritten with only the new items. Expected: no save until the load succeeds, and none at all if it fails (Task 6 test `history is not saved before the saved history has loaded`).
2. **Duplicate ticket keys after restore or remove.** Message tickets are keyed `msg:${tickets.length}`, so a restored or removed item makes the next message reuse a key, and Svelte's keyed `{#each}` throws. Expected: keys stay unique (Task 6 test `message keys stay unique next to restored items`).
3. **A saved download folder that no longer exists or can't be created** (an unplugged USB drive, for example). Expected: the app still starts, using the default folder (Task 3 test `unusable_saved_folder_falls_back`).
4. **Changing the PIN after a sender has been locked out.** Expected: the new PIN starts with a clean slate, and the old wrong guesses are forgotten (Task 2 test `changing_the_pin_clears_lockouts`).
5. **A hand-edited `settings.json` with a blank alias.** Expected: fall back to defaults instead of announcing an empty name (Task 3 test `blank_alias_in_file_uses_defaults`).

```rust
pub fn write_atomic(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
    let mut tmp = path.as_os_str().to_owned();
    tmp.push(".tmp");
    let tmp = std::path::PathBuf::from(tmp);
    let result = (|| {
        let mut f = std::fs::File::create(&tmp)?;
        f.write_all(bytes)?;
        f.sync_all()?;
        // Replaces an existing file on Windows too (MoveFileEx REPLACE_EXISTING).
        std::fs::rename(&tmp, path)
    })();
    if result.is_err() {
        let _ = std::fs::remove_file(&tmp);
    }
    result
}
```

```rust
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Settings {
    pub alias: String,
    pub download_dir: PathBuf,
    /// None = no PIN.
    pub pin: Option<String>,

impl Settings {
    fn normalized(mut self) -> Result<Self> {
        let alias: String = self.alias.trim().chars().take(MAX_ALIAS).collect();
        if alias.trim().is_empty() {
            return Err(Error::Invalid("Device name can't be empty".into()));

        self.alias = alias.trim_end().to_string();

            Error::Invalid(format!("Can't use {}: {e}", self.download_dir.display()))
        })?;
        Ok(self)
    }
}
```

```rust
use sendit_core::{write_atomic, Settings};
use serde::{Deserialize, Serialize};
use serde_json::Value;
use std::path::{Path, PathBuf};

pub const SETTINGS: &str = "settings.json";
pub const HISTORY: &str = "history.json";
pub const HISTORY_CAP: usize = 500;

/// settings.json, and what the Settings page reads and writes.
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct AppSettings {
    pub alias: String,
    pub download_dir: PathBuf,
    pub pin: Option<String>,
    pub close_to_tray: bool,
}

impl AppSettings {
    pub fn core(&self) -> Settings {
        Settings {
            alias: self.alias.clone(),
            download_dir: self.download_dir.clone(),
            pin: self.pin.clone(),
        }
    }

    pub fn from_core(s: Settings, close_to_tray: bool) -> Self {
        Self {
            alias: s.alias,
            download_dir: s.download_dir,
            pin: s.pin,
            close_to_tray,
        }
    }
}

/// A missing, unreadable or hand-broken file means `defaults`.
pub fn load_settings(path: &Path, defaults: AppSettings) -> AppSettings {
    std::fs::read(path)
        .ok()
        .and_then(|b| serde_json::from_slice::<AppSettings>(&b).ok())
        .filter(|s| !s.alias.trim().is_empty())
        .unwrap_or(defaults)
}

pub fn save_settings(path: &Path, s: &AppSettings) -> std::io::Result<()> {
    write_atomic(path, &serde_json::to_vec_pretty(s)?)
}

/// Saved tickets, oldest first. A file that can't be read or parsed is
/// moved to `history.json.bad` so the next save doesn't destroy it.
pub fn load_history(path: &Path) -> Vec<Value> {
    let parsed = match std::fs::read(path) {
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Vec::new(),
        Err(e) => Err(e.to_string()),
        Ok(b) => serde_json::from_slice::<Vec<Value>>(&b).map_err(|e| e.to_string()),
    };
    parsed.unwrap_or_else(|e| {
        eprintln!("history.json unreadable ({e}); keeping it as history.json.bad");
        let mut bad = path.as_os_str().to_owned();
        bad.push(".bad");
        let _ = std::fs::rename(path, PathBuf::from(bad));
        Vec::new()
    })
}

/// Keeps the newest `HISTORY_CAP` items (the list is oldest first).
pub fn save_history(path: &Path, mut items: Vec<Value>) -> std::io::Result<()> {
    if items.len() > HISTORY_CAP {
        items.drain(..items.len() - HISTORY_CAP);
    }
    write_atomic(path, &serde_json::to_vec(&items)?)
}

/// The saved download folder if it can still be used (an unplugged drive
/// can't), otherwise `fallback`.
pub fn usable_dir(saved: &Path, fallback: PathBuf) -> PathBuf {
    if std::fs::create_dir_all(saved).is_ok() {
        saved.to_path_buf()
    } else {
        fallback
    }
}
```

```ts
import type { State, Ticket, TicketStatus } from './state';

const FINISHED: TicketStatus[] = ['done', 'failed', 'declined', 'cancelled', 'expired', 'message'];

export const isFinished = (t: Ticket) => FINISHED.includes(t.status);

/** What goes in history.json: finished items, oldest first, without live-only fields. */
export function toSaved(tickets: Ticket[]): Ticket[] {
  return tickets
    .filter(isFinished)
    .map((t) => {
      const c = { ...t };
      delete c.speeds;
      delete c.lastAt;
      return c;
    })
    .sort((a, b) => (a.doneAt ?? a.at) - (b.doneAt ?? b.at));
}

/** Saved items go before anything that arrived while loading. */
export function restore(s: State, saved: Ticket[]): State {
  const have = new Set(s.tickets.map((t) => t.key));
  return { ...s, tickets: [...saved.filter((t) => !have.has(t.key)), ...s.tickets] };
}

/** "Clear history": forget finished items; files on disk are untouched. */
export const clearFinished = (s: State): State => ({ ...s, tickets: s.tickets.filter((t) => !isFinished(t)) });
```
