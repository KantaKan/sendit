# sendit Plan 2: Desktop app (Tauri 2 + Svelte 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop app on top of `sendit-core` that implements the spec's v1 UX: a chat layout with "Ticket v3" tickets, DiceBear thumbs avatars, and flows A/B/C.

**Architecture:** `app/` holds a Vite + Svelte 5 + TypeScript frontend and `app/src-tauri/`, a Tauri 2 crate that owns one `sendit_core::Node`. It exposes the Node as commands and forwards every core `Event` to the webview as a `core-event`. The frontend talks only through a `Bridge` interface, which has a Tauri implementation and a mock implementation. UI state is a pure reducer (`apply(state, event)`), so it is unit-testable. Playwright drives the real UI against the mock bridge.

**Tech Stack:** Tauri 2 (+ the dialog, notification and opener plugins), Svelte 5 (runes), Vite, TypeScript, @dicebear/core + @dicebear/collection (thumbs), @fontsource fonts, Vitest + @testing-library/svelte, Playwright, npm.

**Spec:** `docs/design/2026-10-23-sendit-v1-design.md` (UX section). Visual reference: the "Ticket v3" mockup.

## Global Constraints

- Dark theme only. Tokens: background `#111113`, surfaces `#1e1e22`/`#222226`, text `#ececea`, accent `#3ecf8e` (the only accent color), danger `#e5533d`.
- Fonts: Familjen Grotesk for UI, JetBrains Mono for metadata (sizes, IPs, percentages), and IBM Plex Sans Thai as the Thai fallback. All are bundled via @fontsource. Nothing loads from the network at runtime.
- No stock icon set and no emoji. File types appear as text. Devices are shown with DiceBear `thumbs` avatars, seeded from the first 16 hex characters of the uppercase fingerprint.
- UI copy is English. No em dashes or en dashes in any UI string.
- Received files are only ever *revealed* in the file manager, never opened or executed from the app.
- Honor `prefers-reduced-motion`. Every interactive element is a real `<button>` or `<input>` with a visible `:focus-visible` ring.
- Commits use the author's git identity only. **No `Co-Authored-By` or tool-attribution trailers.**
- Windows builds use the MSVC toolchain (`stable-x86_64-pc-windows-msvc`).
- CI stays green on Windows, macOS and Linux after every task.

## Review Focus

1. **An incoming request from a sender the core never stored** (unverified, so not in `devices`) must still get a conversation and a ticket. Reducer test in Task 4.
2. **The user clicks Accept after the core's request timeout.** The ticket must show "Expired", not hang on "Starting…". Store test in Task 6.
3. **The user accepts into a folder without enough space.** Show the error and return the ticket to pending, so they can pick another folder or decline. Store test in Task 6.
4. **Files dropped with no device selected.** Show a clear message and send nothing. Store test in Task 6 and e2e test in Task 10.
5. **Huge batches and long or Thai file names** must not break the layout. The request lists 4 files plus "and N more", and names truncate with an ellipsis. Component test in Task 7.

```rust
//! The desktop shell: one sendit `Node`, exposed to the webview as commands,
//! with every core event forwarded as `core-event`.
use sendit_core::{
    protocol::DEFAULT_PORT, trust::KnownDevice, Config, Decision, Device, Error, Node,
};
use serde::Serialize;
use std::{
    net::{IpAddr, SocketAddr},
    path::PathBuf,
};
use tauri::{Emitter, Manager, State};
use tokio::sync::broadcast::error::RecvError;

#[derive(Serialize, Debug)]
#[serde(rename_all = "camelCase")]
pub struct AppInfo {
    pub alias: String,
    pub fingerprint: String,
    pub port: u16,
    pub port_fallback: bool,
    pub download_dir: PathBuf,
}

pub fn app_info(node: &Node) -> AppInfo {
    AppInfo {
        alias: node.info().alias,
        fingerprint: node.fingerprint().to_string(),
        port: node.port(),
        port_fallback: node.port_fallback(),
        download_dir: node.download_dir().to_path_buf(),
    }
}

/// "192.168.1.5" or "192.168.1.5:53317".
pub fn parse_addr(s: &str) -> Result<SocketAddr, String> {
    let s = s.trim();
    s.parse::<SocketAddr>()
        .or_else(|_| s.parse::<IpAddr>().map(|ip| SocketAddr::new(ip, DEFAULT_PORT)))
        .map_err(|_| format!("{s:?} is not an IP address"))
}

/// Transfer failures already reach the UI as events; only setup errors
/// (unknown device, changed key, unreadable file) come back here.
pub async fn send_files_impl(node: &Node, fingerprint: &str, paths: Vec<PathBuf>) -> Result<(), String> {
    match node.send(fingerprint, paths, None).await {
        Ok(_) | Err(Error::Transfer(_)) => Ok(()),
        Err(e) => Err(e.to_string()),
    }
}

#[tauri::command]
fn info(node: State<'_, Node>) -> AppInfo {
    app_info(&node)
}

#[tauri::command]
fn devices(node: State<'_, Node>) -> Vec<Device> {
    node.devices()
}

#[tauri::command]
fn known_devices(node: State<'_, Node>) -> Vec<KnownDevice> {
    node.known_devices()
}

#[tauri::command]
async fn send_files(node: State<'_, Node>, fingerprint: String, paths: Vec<PathBuf>) -> Result<(), String> {
    send_files_impl(&node, &fingerprint, paths).await
}

#[tauri::command]
fn respond(node: State<'_, Node>, request_id: String, accept: bool, dest: Option<PathBuf>) -> Result<(), String> {
    let decision = if accept { Decision::Accept { dest } } else { Decision::Decline };
    node.respond(&request_id, decision).map_err(|e| e.to_string())
}

#[tauri::command]
fn cancel(node: State<'_, Node>, transfer_id: String) -> bool {
    node.cancel(&transfer_id)
}

#[tauri::command]

    node.announce();
}

    Ok(node.scan().await)
}

    let addr = parse_addr(&addr)?;
    node.add_peer(addr).await.map_err(|e| e.to_string())

    node.block(&fingerprint);
}

    node.set_verified(&fingerprint, verified);
}

        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_notification::init())
        .plugin(tauri_plugin_opener::init())
        .setup(|app| {
            let data = app.path().app_data_dir()?;

                .download_dir()
                .map(|d| d.join("sendit"))

                        Err(RecvError::Closed) => break,

            set_verified
```

```ts
import type { CoreEvent, Device, Direction, FailReason, FileMeta, KnownDevice } from './types';

export type TicketStatus =
  | 'pending' | 'accepting' | 'live' | 'done' | 'failed' | 'declined' | 'cancelled' | 'expired';

export interface Ticket {
  key: string;
  transferId?: string;
  requestId?: string;
  peer: string;
  direction: Direction;
  files: FileMeta[];
  total: number;
  bytes: number;
  status: TicketStatus;
  reason?: FailReason;
  paths: string[];
  sources: string[];
  senderVerified?: boolean;
  fitsOnDisk?: boolean;
  /** ms timestamp the ticket appeared */
  at: number;
}

export interface State {
  devices: Record<string, Device>;
  known: KnownDevice[];
  tickets: Ticket[];
  /** suspect fingerprint -> fingerprint it replaced */
  identityChanges: Record<string, string>;
}

export const initial = (): State => ({ devices: {}, known: [], tickets: [], identityChanges: {} });

function patch(s: State, pick: (t: Ticket) => boolean, change: (t: Ticket) => Partial<Ticket>): State {
  const i = s.tickets.findIndex(pick);
  if (i < 0) return s;
  const tickets = s.tickets.slice();
  tickets[i] = { ...tickets[i], ...change(tickets[i]) };
  return { ...s, tickets };
}

const byTransfer = (id: string) => (t: Ticket) => t.transferId === id;
const byRequest = (id: string) => (t: Ticket) => t.requestId === id;

export function apply(s: State, e: CoreEvent, now: number): State {
  switch (e.type) {
    case 'deviceUpdated': {
      const identityChanges = { ...s.identityChanges };
      if (e.device.trust !== 'suspect') delete identityChanges[e.device.fingerprint];
      return { ...s, devices: { ...s.devices, [e.device.fingerprint]: e.device }, identityChanges };
    }
    case 'identityChanged':
      return {
        ...s,
        devices: { ...s.devices, [e.device.fingerprint]: e.device },
        identityChanges: { ...s.identityChanges, [e.device.fingerprint]: e.oldFingerprint },
      };
    case 'incomingRequest': {
      const r = e.request;
      const devices = s.devices[r.from.fingerprint] ? s.devices : { ...s.devices, [r.from.fingerprint]: r.from };
      const ticket: Ticket = {
        key: `req:${r.requestId}`,
        requestId: r.requestId,
        peer: r.from.fingerprint,
        direction: 'incoming',
        files: r.files,
        total: r.totalSize,
        bytes: 0,
        status: 'pending',
        paths: [],
        sources: [],
        senderVerified: r.senderVerified,
        fitsOnDisk: r.fitsOnDisk,
        at: now,
      };
      return { ...s, devices, tickets: [...s.tickets, ticket] };
    }
    case 'transferStarted': {
      if (e.direction === 'incoming') {
        const accepting = (t: Ticket) => t.status === 'accepting' && t.peer === e.peer;
        if (s.tickets.some(accepting)) {
          return patch(s, accepting, () => ({ transferId: e.transferId, status: 'live', files: e.files, total: e.total }));
        }
      }
      const ticket: Ticket = {
        key: e.transferId,
        transferId: e.transferId,
        peer: e.peer,
        direction: e.direction,
        files: e.files,
        total: e.total,
        bytes: 0,
        status: 'live',
        paths: [],
        sources: e.sources,
        at: now,
      };
      return { ...s, tickets: [...s.tickets, ticket] };
    }
    case 'progress':
      return patch(s, byTransfer(e.transferId), () => ({ bytes: e.bytes }));
    case 'transferDone':
      return patch(s, byTransfer(e.transferId), (t) => ({ status: 'done', bytes: t.total, paths: e.paths }));
    case 'transferFailed': {
      const status: TicketStatus =
        e.reason.kind === 'cancelled' ? 'cancelled' : e.reason.kind === 'declined' ? 'declined' : 'failed';
      return patch(s, byTransfer(e.transferId), () => ({ status, reason: e.reason }));
    }
  }
}

export const markAccepting = (s: State, requestId: string) => patch(s, byRequest(requestId), () => ({ status: 'accepting' }));
export const markPending = (s: State, requestId: string) => patch(s, byRequest(requestId), () => ({ status: 'pending' }));
export const markDeclined = (s: State, requestId: string) => patch(s, byRequest(requestId), () => ({ status: 'declined' }));
export const markExpired = (s: State, requestId: string) => patch(s, byRequest(requestId), () => ({ status: 'expired' }));

export const ticketsFor = (s: State, fp: string) => s.tickets.filter((t) => t.peer === fp);

const byAlias = (a: { alias: string }, b: { alias: string }) =>
  a.alias.localeCompare(b.alias, undefined, { sensitivity: 'base' });

export const nearby = (s: State) => Object.values(s.devices).sort(byAlias);

export const seenBefore = (s: State) => s.known.filter((k) => !s.devices[k.fingerprint]).sort(byAlias);
```

```ts
const UNITS = ['B', 'KB', 'MB', 'GB', 'TB'];

export function formatBytes(n: number): string {
  let v = n;
  let i = 0;
  while (v >= 1000 && i < UNITS.length - 1) {
    v /= 1000;
    i++;
  }
  if (i === 0) return `${n} B`;
  return `${v < 10 ? v.toFixed(1) : Math.round(v)} ${UNITS[i]}`;
}

export const percent = (bytes: number, total: number) =>
```

```ts
/** Tauri's listeners are async to attach; give the UI a sync unsubscribe. */
function subscribe<T>(attach: (cb: T) => Promise<() => void>, cb: T): () => void {
  let off: (() => void) | undefined;
  let dead = false;
  void attach(cb).then((u) => (dead ? u() : (off = u)));
  return () => {
    dead = true;
    off?.();
  };
}
```

```ts
import type { Bridge } from './bridge';
import {
  apply, initial, markAccepting, markDeclined, markExpired, markPending, type State, type Ticket,
} from './state';
import type { AppInfo, CoreEvent, Device } from './types';

export function createStore(bridge: Bridge) {
  let state = $state<State>(initial());
  let me = $state<AppInfo | null>(null);
  let selected = $state<string | null>(null);
  let searching = $state(false);
  let dragging = $state(false);
  let error = $state<string | null>(null);
  const fail = (e: unknown) => {
    error = String(e);
  };
  const addDevice = (device: Device) => {
    state = apply(state, { type: 'deviceUpdated', device }, Date.now());
  };
  const refreshKnown = () => {
    void bridge.knownDevices().then((known) => {
      state = { ...state, known };
    });
  };

  function onEvent(e: CoreEvent) {
    state = apply(state, e, Date.now());
    if (e.type === 'incomingRequest') {
      selected ??= e.request.from.fingerprint;
      if (!document.hasFocus()) {
        bridge.notify(`${e.request.from.alias} wants to send files`, `${e.request.files.length} file(s)`);
      }
    }
    if (e.type === 'identityChanged' && selected === e.oldFingerprint) selected = e.device.fingerprint;
    if (e.type === 'deviceUpdated' || e.type === 'identityChanged') refreshKnown();
  }

  function send(paths: string[]) {
    if (!paths.length) return;
    if (!selected) {
      error = 'Pick a device first, then drop the files on it.';
      return;
    }
    bridge.sendFiles(selected, paths).catch(fail);
  }

  function accept(requestId: string, dest?: string) {
    state = markAccepting(state, requestId);
    bridge.respond(requestId, true, dest).catch((e) => {
      const msg = String(e);
      if (msg.includes('no pending request')) {
        state = markExpired(state, requestId);
      } else {
        state = markPending(state, requestId);
        error = msg;
      }
    });
  }

  return {
    get state() { return state; },
    get me() { return me; },
    get selected() { return selected; },
    get searching() { return searching; },
    get dragging() { return dragging; },
    get error() { return error; },
    get selectedDevice(): Device | null { return selected ? (state.devices[selected] ?? null) : null; },

    start(): () => void {
      const offEvent = bridge.onEvent(onEvent);
      const offDrag = bridge.onDrag((d) => {
        dragging = d.kind === 'enter';
        if (d.kind === 'drop') send(d.paths);
      });
      void (async () => {
        try {
          me = await bridge.info();
          const [devices, known] = await Promise.all([bridge.devices(), bridge.knownDevices()]);
          for (const d of devices) addDevice(d);
          state = { ...state, known };
        } catch (e) {
          fail(e);
        }
      })();
      return () => {
        offEvent();
        offDrag();
      };
    },
    select(fp: string) { selected = fp; },
    send,
    async chooseFiles() { send(await bridge.pickFiles()); },
    accept,
    async acceptElsewhere(requestId: string) {
      const dir = await bridge.pickFolder();
      if (dir) accept(requestId, dir);
    },
    decline(requestId: string) {
      state = markDeclined(state, requestId);
      bridge.respond(requestId, false).catch(() => {});
    },
    cancel(transferId: string) { bridge.cancel(transferId).catch(fail); },
    retry(t: Ticket) {
      if (t.sources.length) bridge.sendFiles(t.peer, t.sources).catch(fail);
    },
    reveal(path: string) { bridge.reveal(path).catch(fail); },
    refresh() {
      searching = true;
      bridge.announce().catch(fail);
      setTimeout(() => (searching = false), 3000);
    },
    async scan() {
      searching = true;
      try {
        for (const d of await bridge.scan()) addDevice(d);
      } catch (e) {
        fail(e);
      } finally {
        searching = false;
      }
    },
    async addPeer(addr: string) {
      const d = await bridge.addPeer(addr);
      addDevice(d);
      selected = d.fingerprint;
    },
```

```ts
    (window as unknown as { __senditSeed: object }).__senditSeed = s;

  await page.goto('/');

  page.evaluate((n) => (window as any).__sendit.calls.filter((c: Call) => c.name === n), name);

test('empty state explains how devices appear', async ({ page }) => {
```
